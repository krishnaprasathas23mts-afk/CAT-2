# Aurora Calculator

A premium, anime/futuristic-inspired calculator built with pure HTML, CSS, and vanilla JavaScript — no frameworks, no libraries.

## Features
- Full arithmetic (add, subtract, multiply, divide, percent, sign toggle)
- Animated aurora background with drifting glow, fog, and floating particles
- Glassmorphic calculator body with an energy-flow border and neon display
- Button hover lift/glow, click ripple + shockwave, and cursor-following ambient light
- Dark / Light theme toggle, saved to Local Storage
- Calculation history panel (view, reuse, clear), saved to Local Storage
- Full keyboard support (digits, operators, Enter, Backspace, Escape, %, .)
- Friendly error handling (e.g. divide by zero) with shake animation + toast
- Fully responsive: mobile, tablet, laptop, desktop, ultra-wide

## Run it
Just open `index.html` in any modern browser. No build step, no dependencies.

## Files
- `index.html` — structure
- `style.css` — all visuals, animations, themes, responsive rules
- `script.js` — calculator engine, history store, UI controller, keyboard support
